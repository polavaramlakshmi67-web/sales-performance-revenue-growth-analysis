# Sales Performance & Revenue Growth Analysis

## Project Overview
An end-to-end data analytics project using Excel, Power Query, MySQL, and Power BI to analyze sales performance, profitability, product trends, and regional performance.

## Business Problem
Sales reporting can require time-consuming manual work, making it difficult to compare performance and identify areas that need attention.

## Project Objectives
- Track key sales and profitability metrics.
- Analyze monthly sales and profit trends.
- Identify top-performing products.
- Compare performance across regions, categories, and customer segments.
- Present insights through an interactive Power BI dashboard.

## Tools & Technologies
- Microsoft Excel
- Power Query
- MySQL
- Power BI
- DAX

## Key Performance Indicators
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Margin

## Project Structure
- `01_Dataset` — Original and cleaned datasets
- `02_Data_Cleaning` — Data preparation documentation
- `03_SQL_Analysis` — SQL queries and screenshots
- `04_PowerBI_Dashboard` — Power BI report
- `05_Screenshots` — Dashboard screenshots
- `06_Business_Insights` — Findings and recommendations

## Dashboard
The interactive dashboard includes KPI cards, a monthly sales trend, top products by sales, profit by region, sales by category, and sales by customer segment, with slicers for exploring the data.

## Business Insights
Findings and recommendations will be documented using verified SQL query results and dashboard analysis.

## Conclusion
This project demonstrates how data cleaning, SQL analysis, and Power BI visualization can support sales performance monitoring and business decision-making.
